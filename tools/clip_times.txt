# Point out the good bit of each game clip. The build script grabs just
# those seconds from the game's YouTube video and makes a small, muted,
# offline clip at clips/clip_<id>.mp4. Games you fill in get moving
# gameplay on the shelf + their game page; the rest keep the YouTube embed.
#
# HOW: put a START time on any game you want. Leave START blank to skip.
#   START  = where to begin, in SS or M:SS   (e.g. 90  or  1:30)
#   LEN    = how many seconds to keep        (blank = 15)
# Pick a START on PURE GAMEPLAY: past the title/intro screens, and away from
# any face-cam or menus, so the clip shows only the game. ~15s works for most.
# Then run:  python3 tools/make_clips.py
# Re-run any time - it only (re)builds rows that changed.
#
