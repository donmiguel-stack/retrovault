# Narration blocks for text-to-speech

One file per spoken block, named by its timecode in the recording. Blocks with
no narration are listed but have no file — leave those silent.

Paste each file into ElevenLabs on its own and keep the output under the same
number, so every audio file lands against its own timecode.

Pace is words per minute. 130–160 is comfortable; up to about 175 is fine and
may run a second past the cut, which is harmless.
