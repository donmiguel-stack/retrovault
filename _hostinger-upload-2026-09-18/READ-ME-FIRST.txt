1. .htaccess  — NEW
   301-redirects www.retrovault.world to retrovault.world. This is the fix
   for the one "Duplicate without user-selected canonical" URL in Search
   Console. It also sends any http request to https in a single hop.

   It is a hidden file (the leading dot). Hostinger's File Manager needs
   "Show hidden files" switched on before you can see or upload it; most
   FTP clients need the same setting.

   If hPanel already has a "redirect www" or "force HTTPS" toggle switched
   on, use that OR this file, not both — two rules can bounce a request
   between them.
